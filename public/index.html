🔗 UTM Tracking

Saber qué anuncios generan ventas en Hotmart

⚡ Genera tus URLs de tracking
Una URL por campaña o anuncio. Pégala como URL de destino en cada anuncio de Meta Ads.
CAMPAÑAS / ANUNCIOS
💡 Hotmart captura el parámetro src automáticamente. Usa nombres cortos sin espacios (ej: MAYO_VIDEO1).
🎯 Parámetros dinámicos de Meta Ads
En lugar de crear una URL por anuncio, usa estas variables en el campo "Parámetros de URL" de tus anuncios. Meta las rellena automáticamente con el nombre real de cada campaña o anuncio.
⭐ RECOMENDADO — Por anuncio + campaña
src={{ad.name}}&xcod={{campaign.name}}
Identifica cada anuncio individual y la campaña a la que pertenece
Por anuncio
src={{ad.name}}
Usa el nombre del anuncio como identificador
Por campaña
src={{campaign.name}}
Agrupa todas las ventas de una campaña completa
¿Cómo pegarlo en Meta?
Edita el anuncio → URL del sitio web = tu URL de Hotmart normal → Parámetros de URL = pega el código copiado arriba.
Meta construye la URL final automáticamente con el nombre real de cada anuncio.
